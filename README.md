# LLM Mystery Framework

基于大语言模型的互动推理游戏主持框架 / An experimental LLM-driven interactive mystery framework.

## 项目简介

本项目探索如何让大语言模型依据预先编写的固定谜底、证据及人物知情范围，主持单人互动推理游戏。玩家通过自然语言或编号选项进行调查、询问与证据论破。

目前是提示词驱动的实验性原型，并非独立软件游戏引擎。

## 当前设计

- 固定案件真相、证据链和推理成立条件。
- 自由调查、人物互动、证据论破和剧情分支。
- 受明确条件约束的特殊能力。
- 结构化状态记录、每五次有效行动的滚动微快照及完整检查点。
- 公开信息与主持侧信息分离；聊天界面中的折叠记录不构成真正的安全隔离。

## 示范战役

《听见雪以前》V3.2-F2/R2+P1：包含五个案件的三篇章测试战役。P1 集成通灵平衡、结构化状态管理、滚动微快照与紧凑显示规则。

当前仓库先发布无剧透项目说明；完整主持资料的公开范围尚待确认。

## 游玩方式

取得适用版本的主持合订本后，在支持长文档上传的新 AI 聊天中上传文件，并要求模型按文件主持游戏，只展示玩家当下可知内容。无需自行编程或部署 API。

## 测试重点

- 证物与人物知情状态是否一致。
- 能否正确执行能力限制、剧情分支和证据判定。
- 连续游玩时微快照是否正确继承，以及完整存档能否恢复。
- 调查操作是否精简，是否出现提前剧透。

跨模型兼容性及 P1 长局稳定性仍待验证。欢迎通过 Issues 提交复现步骤、模型名称及游戏版本；请避免在公开反馈中直接展示谜底或私人信息。
