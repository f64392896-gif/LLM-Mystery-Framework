# LLM Mystery Framework

基于大语言模型的互动推理游戏主持框架 / An experimental LLM-driven interactive mystery framework.

## 项目简介

本项目探索如何让大语言模型依据预先编写的固定谜底、证据及人物知情范围，主持单人互动推理游戏。玩家通过自然语言或编号选项进行调查、询问与证据论破。

目前是提示词驱动的实验性原型，并非独立软件游戏引擎。

## 当前设计

- 固定案件真相、证据链和推理成立条件。
- 自由调查、人物互动、证据论破和剧情分支。
- 受明确条件约束的特殊能力。
- 结构化状态记录、每五次有效行动的滚动微快照及完整检查点。
- 公开信息与主持侧信息分离；聊天界面中的折叠记录不构成真正的安全隔离。

## 示范战役

《听见雪以前》V3.2-F2/R2+P1-O1（原创主角公开测试版）：包含五个案件的三篇章测试战役。P1 集成通灵平衡、结构化状态管理、滚动微快照与紧凑显示规则。

**现已发布。** [主持合订本（含全部剧透）](campaigns/hear-before-snow/host-v3.2-p1-o1.zh-CN.md)。建议下载原始 Markdown 文件，不阅读正文，直接交给主持 AI。主角为久濑真帆与篠崎理央。

## 游玩方式

1. [下载公开测试版 Markdown](https://raw.githubusercontent.com/f64392896-gif/LLM-Mystery-Framework/main/campaigns/hear-before-snow/host-v3.2-p1-o1.zh-CN.md)。
2. 在支持长文档上传的 AI 平台新建聊天，上传文件。
3. 发送以下开局口令：

> 请将附件作为主持资料。我扮演久濑真帆，你负责主持《听见雪以前》。严格遵循附件中的固定真相、证据规则、特殊能力与滚动微快照机制，只展示我当下可知的内容。采用适合手机的编号选项，并允许自由行动。开始第一案。

无需自行编程或部署 API。推荐高能力模型；免费或轻量模型也可参与兼容性测试。旧角色版存档不建议直接载入。

## 测试重点

参见 [测试指南](TESTING.md) 与 [版本记录](CHANGELOG.md)。

- 证物与人物知情状态是否一致。
- 能否正确执行能力限制、剧情分支和证据判定。
- 连续游玩时微快照是否正确继承，以及完整存档能否恢复。
- 调查操作是否精简，是否出现提前剧透。

跨模型兼容性及 P1 长局稳定性仍待验证。欢迎通过 Issues 提交复现步骤、模型名称及游戏版本；请避免在公开反馈中直接展示谜底或私人信息。
